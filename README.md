# Project-Append-Excel-Files-from-Gmail
This project demonstrates how to retrieve Excel attachments from Gmail and prepare data for consolidation using Microsoft Excel, Power Query, Google Apps Script, and Web App integration. It focuses on data extraction, transformation, and automation for Data Analytics.
